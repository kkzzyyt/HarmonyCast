# 批量设备巡检

在左侧「批量巡检」分组中打开「设备巡检」，导入 IP TXT 或粘贴地址列表，点击「开始巡检」。

每台设备依次执行 `hdc tconn IP:端口`、读取设备信息、`hdc tconn IP:端口 -remove`，断开命令结束后再处理下一台。连接、采集失败或超时后也会尝试断开当前目标，并继续后续设备。断开失败会显示在该设备的备注中。

巡检使用独立列表，执行期间暂停投屏、日志采集和调试设备轮询，并禁用调试导航，防止临时巡检连接触发自动投屏。巡检结束或停止后恢复调试导航及原有设备轮询。只对列表中的当前目标执行断开；列表中已在调试的设备也会在巡检后断开。

## IP TXT 格式

支持 IPv4 地址和 `IPv4:端口`，默认端口为 `8710`。每行一个地址，也可用空格、逗号或分号分隔，`#` 后为注释。相同 IP 和端口自动去重，不同端口作为不同目标。无效地址会显示行号，修正后才能开始。

```text
# 设备 IP，默认端口 8710
192.0.2.10
192.0.2.11
192.0.2.12:9000 # 自定义端口
```

可下载[示例 TXT](inspection-ips.example.txt)，替换成实际地址。支持 UTF-8（含 BOM）及带 BOM 的 UTF-16 LE/BE 文本；单个文件不超过 1 MiB，单次不超过 10000 个目标。设备需开启 HDC 网络调试，并完成主机授权。

## 信息与导出

| 类别 | 导出字段 |
| --- | --- |
| 巡检记录 | 目标 IP、HDC 端口、结果、巡检时间、备注 |
| 运行时间 | 自上次启动至今的天/时/分/秒、总秒数 |
| 网络 | 各非回环网卡的 IPv4、MAC，保留网卡名以便对应 |
| 内存 | 总量、已用、可用（MiB）、使用率 |
| 存储 | `/data` 总容量、可用容量（GiB）、使用率 |
| 系统 | 型号、序列号、系统/API 版本、CPU 架构、内核、设备时间 |
| 负载 | CPU 在 1、5、15 分钟内的系统平均负载 |

内存可用量取 `/proc/meminfo` 的 `MemAvailable`，已用量为总量减可用量。设备不提供该字段时，已用量和使用率留空；未读取到的信息不会填成 0。运行时间取 `/proc/uptime`，CPU 平均负载取 `/proc/loadavg`，它表示排队负载而非 CPU 使用百分比。

连接和采集各自有超时限制，界面异步更新进度。点击「停止」会终止当前连接或读取，完成当前目标的断开尝试后结束，尚未执行的设备标记为「已停止」。正常关闭窗口时也会尝试清理当前巡检连接。

结束或停止后点击「导出表格」，保存为 CSV，可直接用 Excel 或 WPS 打开。表格包含所有目标及失败原因，使用 UTF-8 BOM 保留中文，转义引号、逗号及换行，并把设备返回的公式形式文本作为普通文本保存。界面表格可横向滚动查看，导出文件还包含完整的系统与容量字段。

表格支持触控板双向逐像素滚动，也可按住 Shift 使用滚轮横向查看。滚动条支持拖动和点击轨道定位，悬停时会显示更清晰的滑块。

## 验证

```bash
cmake --build build -j 8
ctest --test-dir build --output-on-failure
```

`InspectionTests` 使用模拟 HDC 覆盖列表导入、计数解析、CSV 转义、逐台连接/断开顺序、失败继续、超时、中止、退出清理和界面状态，不会连接实际设备。不同设备固件可用的系统参数和读取权限仍需实机核对。
