# Security reporting

For vulnerabilities, use the repository's **Security → Report a vulnerability**
when available. If private reporting is unavailable, open an issue asking for a
private contact channel without publishing exploit details or private logs.

Useful reports include the affected revision, the host/device versions, the
attack preconditions and minimal reproduction steps. The maintainer will triage
reports as availability permits; there is no guaranteed response time.

HarmonyCast runs HDC with the permissions of the local user and the connected
device's debug account. Use it with devices and services you are authorized to
debug. Root development images and production/commercial firmware have different
capabilities. The project does not provide a device permission bypass.
